# The Funniest Out-of-Office

A make.fun entry for [The Funniest Out-of-Office](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf) — one line of out-of-office auto-reply, the funniest I could make it, in 140 characters or fewer.

`main.ts` (Node 22, stdlib only, no network, no secrets) writes the line to `/output/entry.txt`:

> Out of office until Monday. I left detailed instructions for my replacement, this auto-reply, and it has already quit.

Run it locally:

```sh
node main.ts
```

The setup is a perfectly ordinary out-of-office; the twist is that the replacement *is* the auto-reply, and it has already quit — the message undermines its own job in its last three words.
